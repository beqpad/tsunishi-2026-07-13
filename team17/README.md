# ルーター周辺環境の工夫によるWi-Fi改善の検証

## 1. 研究の背景と目的

学校内の建物全体で見たとき、WiFiの電波強度や通信品質にムラがあり、授業や学習活動に支障が出ている場面があると考えられる。本研究では、ルーター（アクセスポイント）の設置数を変えるのではなく、ルーター周辺に特定の物を置くことで電波特性が変化するかを実験的に検証する。機器を増やさずにコストゼロで試せる改善策としての可能性を探る。

---

## 2. リサーチクエスチョンと仮説

**RQ：** 津西高校のWi-Fi環境を良くするためにはどうすればいいか。

**仮説：** ルーターの近くに特定の物を置くことによって、Wi-Fiの速度が変化するのではないか。

## 3. 前提知識・現状整理

### 電波の基礎特性

* **光の一種：** 電波は電磁波の一種で、光と同じ速度（秒速約30万km）で空間を伝わる。
* **周波数と波長：** 周波数が高いほど波長は短く、直進性が増して情報量を多く送れる。
* **回折と透過：** 周波数が低いほど障害物を回り込み（回折）、壁などを透過しやすい。
* **減衰特性：** 距離の2乗に比例して電波は弱くなるほか、壁や人体に吸収・反射されて減衰する。

### WiFi規格の比較

| 規格名 | 通称 | 主な周波数帯 | 電波特性とメリット | デメリット・課題 |
| :--- | :--- | :--- | :--- | :--- |
| 802.11b/g/n | Wi-Fi 4 | 2.4GHz | 遠くまで届く。壁・障害物に強い | 電子レンジ・Bluetoothと干渉しやすく混雑する |
| 802.11a/ac | Wi-Fi 5 | 5GHz | 干渉が少なく安定・高速 | 障害物に弱く壁を透過しにくい |
| 802.11ax | Wi-Fi 6/6E | 2.4/5/6GHz | 混雑に強い（OFDMA技術）。6GHz帯はさらに高速 | 対応端末が必要。6GHzはさらに障害物に弱い |
| 802.11be | Wi-Fi 7 | 2.4/5/6GHz | 超低遅延。複数帯域の同時利用（MLO）が可能 | 機材コストが高い |

### 電波の反射・吸収・遮蔽の性質

「特定の物を置く」アプローチに関わる重要な基礎知識。

* **反射：** 電波は金属面などで反射する。反射板（アルミ板など）をアンテナの背後に置くことで、特定方向への電波放射を強化できる可能性がある。
* **吸収：** カーボン系素材や水分を含む物体は電波を吸収し、干渉を減らす効果がある場合がある。
* **遮蔽（シールド）：** 金属製の囲いは電波を遮断するため、意図せず電波を弱めることがある。

### 実験条件の統制

1. 計測に使用する端末（スマホやPC）の機種・OSバージョンを統一する（端末アンテナ性能の差を排除するため）。
2. 「物を置く前」と「物を置いた後」を同じ時間帯・同じ混雑度の条件で計測する。
3. 物の種類・形状・設置位置は1変数ずつ変えて計測し、複数の変数が同時に変わらないよう管理する。

## 5. 計測方法と評価指標

### ① 物理層・電波強度

* **RSSI（受信信号強度）：** 単位はdBm。一般に−60dBm以上なら良好、−80dBm以下は切断リスクあり。
* **SNR（信号対雑音比）：** 背景ノイズに対してWiFi電波がどれだけ強いかの比率（dB）。数値が高いほど高品質。

### ② ネットワーク層・通信品質

* **スループット（Throughput）：** 実際の通信速度（Mbps）。アップロード・ダウンロード双方を計測。
* **パケットロス率：** 送信データの何%が途中で消失したか。
* **レイテンシ・ジッター：** 応答速度（遅延時間）とそのばらつき。

### ③ 計測ツールとアプローチ

* **ヒートマップ作成：** NetSpotなどの専用ソフトで間取り図上にRSSIを可視化する。
* **定点計測：** 物を置く前後で同一位置にて繰り返し計測し、数値の変化を比較する。
