# WiFi電波環境改善に関する実践研究計画書（案）

本研究は、学校内のWiFi電波課題に対して定量的なアプローチで改善施策を検証し、最終的に県教育委員会等への「設備投資提案書」として結実させるまでを一連のプロセスとする実践研究である。

## 2. 前知識（電波の基礎と規格特性）

### そもそも「電波」の特徴
* **光の一種**：電波は電磁波の一種であり、光と同じ速度（秒速約30万 km）で空間を伝わります。
* **周波数と波長**：周波数が高いほど波長は短くなり、直進性が増して情報量を多く送れます。
* **回折と透過**：周波数が低いほど障害物を回り込み（回折）、壁などを透過しやすくなります。
* **減衰特性**：距離の2乗に比例して電波は弱くなる（自由空間伝搬損失）ほか、壁や人体に吸収・反射されて減衰します。

### WiFi規格による電波特性の比較
WiFiの規格（IEEE 802.11）は、使用する周波数帯（2.4GHz / 5GHz / 6GHz）によって特性が大きく異なります。

| 規格名 | 通称 | 主な周波数帯 | 最大通信速度 | 電波特性とメリット | デメリット・課題 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **802.11b/g/n** | Wi-Fi 4 | **2.4GHz** | 数十〜数百 Mbps | 遠くまで届く。壁や障害物に強い。 | 電子レンジやBluetoothと干渉しやすい。混雑する。 |
| **802.11a/ac** | Wi-Fi 5 | **5GHz** | 数百Mbps〜6.9Gbps | 電波干渉が少ない。通信が安定・高速。 | 障害物に弱い。壁を透過しにくい。 |
| **802.11ax** | Wi-Fi 6/6E | **2.4 / 5 / 6GHz** | 最大9.6Gbps | 混雑に強い（OFDMA技術）。6GHz帯はさらに高速。 | 対応端末が必要。6GHzはさらに障害物に弱い。 |
| **802.11be** | Wi-Fi 7 | **2.4 / 5 / 6GHz** | 最大46Gbps | 超低遅延。複数帯域の同時利用（MLO）が可能. | 機材コストが高い。 |

## 3. 施策の方向性と研究におけるアプローチ

### 施策A：設置数を増やす（多点設置・セル小規模化）
* **アプローチ**：アクセスポイント（AP）の数を増やし、1台あたりのカバーエリア（セル）を小さくします。
* **メリット**：端末とAPの距離が縮まるため、高周波帯（5GHz/6GHz）の高速通信を維持しやすくなります。
* **研究としての課題（要検証）**：隣り合うAP同士の電波干渉（チャネル干渉）の制御、および移動時のスムーズな接続切り替え（ローミング）の最適化。

### 施策B：電波の出力を高める（高出力化・高利得アンテナ）
* **アプローチ**：APの送信出力を上げる、または指向性アンテナを用いて特定の方向へ電波を強く飛ばします。
* **メリット**：機器の設置台数を最小限に抑えられ、導入・配線コストを削減できます。
* **研究としての課題（要検証）**：電波法による出力制限（空中線電力の法規制）の遵守。また、「APの電波は端末に届くが、出力の弱いスマホからの電波がAPに届かない」という**非対称性の問題（隠れ端末問題など）**の発生。

## 4. 効果の計測方法（研究の評価指標）

施策前後の変化を定量的に比較するため、以下の3つのレイヤーでデータを計測します。

### ① 物理層・電波強度の計測（電波そのものの評価）
* **RSSI（受信信号強度）**：端末が受信した電波の強さ（単位: dBm）。一般に -60 dBm 以上なら良好、-80 dBm 以下は切断リスクあり。
* **SNR（信号対雑音比）**：背景ノイズ（雑音）に対して、どれだけ強いWiFi電波が届いているかの比率（単位: dB）。数値が高いほど高品質。

### ② ネットワーク層・通信品質の計測（ユーザー体感の評価）
* **スループット（Throughput）**：実際の通信速度（実効速度、単位: Mbps）。上下（アップロード/ダウンロード）を計測。
* **パケットロス率（Packet Loss）**：送信されたデータの何%が途途中消滅したか。リアルタイム通信（Web会議やオンラインCBTなど）の安定性に直結。
* **レイテンシ・ジッター（Latency / Jitter）**：応答速度（遅延時間）とそのばらつき。

### ③ 計測のアプローチとツール
* **ヒートマップ作成**：専用ソフト（例：NetSpotなど）を使い、間取り図上に電波強度（RSSI）を視覚化（カラーマップ化）してエリアの死角をあぶり出す。
* **定点観測と移動観測**：
  * **定点**：特定の座席や部屋の隅で、時間帯（混雑時・空いている時）ごとの変化を計測。
  * **移動**：歩きながら計測し、AP間のローミングがスムーズに行われるか（瞬断の有無）を確認。

## 5. 行政（教育委員会）への提案書構成（最終アウトプット）

研究活動の成果は、以下の構成で予算要求のための提案書として集約する。

### 第1章：本提案の背景と目的（教育的大義名分）
* 国の教育施策（GIGAスクール構想、デジタル教科書、MEXCBT等）との連動性。
* 電波不良による「教育活動の機会損失（授業の中断）」の現状。
* 防災拠点（避難所）としての通信インフラ強靭化の必要性。

### 第2章：学校における通信環境の現状と課題
* 計測によって得られた「施策前」データの提示（電波ヒートマップ、パケットロス率の数値など）。
* 勘や経験ではなく、データに基づく客観的なボトルネックの特定。

### 第3章：電波改善施策の比較検証と効果（研究成果）
* 特定教室等で行った小規模な実証実験の「施策後」データ。
* 設置数変更、または出力変更によって通信品質が何％改善したかのエビデンス。

### 第4章：必要予算の試算および導入プラン
* 全校（または対象エリア）へ横展開した場合の工事費・機器代の試算。
* 財政負担を軽減するための「段階的整備プラン（スモールスタート）」の提示。
* 国の補助金・交付金の活用可能性。

## 6. 研究デザイン（満たすべき実験条件）

1. **評価環境の固定**：計測に使用する端末（スマホやPC）の機種やOSバージョンを統一する（端末のアンテナ性能による差を排除するため）。
2. **比較基準の策定**：全く同じ時間帯・同じ周辺混雑度（可能な限り同一条件）で「施策前」と「施策後」のデータを取得する。
3. **他校への横展開性の意識**：本校の構造（例：標準的な鉄筋コンクリート造）における最適解を導き出し、県内他校のモデルケースとなる設計を目指す。
