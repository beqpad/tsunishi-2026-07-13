# 西考 2026 — メンター用アンチョコ

三重県立津西高等学校「西考」（2026年度）における各班の研究テーマと計画書の目次です。
生徒向けではなく、メンターおよび担当教員間での事前共有用です。

---

## 各計画書の共通セクション構成

すべての班のREADMEは以下のセクション構成で統一されています。

| # | セクション | 内容 |
| :--- | :--- | :--- |
| 1 | 研究の背景と目的 | なぜこのテーマか、何を明らかにしたいか |
| 2 | リサーチクエスチョンと仮説 | 公式表のRQ・仮説をベースに記載 |
| 3 | 前提知識・現状整理 | 実験に必要な基礎知識、現状の課題（不要な班は省略） |
| 4 | 研究デザインと実験計画 | 条件統制、比較軸、対象者など |
| 5 | 計測方法と評価指標 | 何をどう測るか |
| 6 | 研究プロセス（フェーズ別） | 序盤・中盤・終盤の流れ（日付なし） |
| 7 | 最終アウトプット（スライド発表構成案） | 発表スライドの章立て案 |
