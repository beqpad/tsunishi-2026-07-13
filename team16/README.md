# ルーターの台数増設によるWi-Fi強化の検証

## 1. 研究の背景と目的

学校内の建物全体で見たとき、WiFiの電波強度や通信品質にムラがあり、授業や学習活動に支障が出ている場面があると考えられる。本研究では、アクセスポイント（ルーター）の設置台数を増やすことでWiFi環境が改善されるかを定量的に検証し、最終的には教育委員会への設備投資提案書として結実させることをゴールとする。

---

## 2. リサーチクエスチョンと仮説

**RQ：** ルーターを増やすことによって、Wi-Fiを強くすることは可能なのか。

**仮説：** アクセスポイントを増設することで、最大接続人数が増え、Wi-Fiの届く範囲も広くなるため、電波が強くなる。

---

## 3. 前提知識・現状整理

### 電波の基礎特性

* **光の一種：** 電波は電磁波の一種で、光と同じ速度（秒速約30万km）で空間を伝わる。
* **周波数と波長：** 周波数が高いほど波長は短く、直進性が増して情報量を多く送れる。
* **回折と透過：** 周波数が低いほど障害物を回り込み（回折）、壁などを透過しやすい。
* **減衰特性：** 距離の2乗に比例して電波は弱くなるほか、壁や人体に吸収・反射されて減衰する。

### WiFi規格の比較

| 規格名 | 通称 | 主な周波数帯 | 電波特性とメリット | デメリット・課題 |
| :--- | :--- | :--- | :--- | :--- |
| 802.11b/g/n | Wi-Fi 4 | 2.4GHz | 遠くまで届く。壁・障害物に強い | 電子レンジ・Bluetoothと干渉しやすく混雑する |
| 802.11a/ac | Wi-Fi 5 | 5GHz | 干渉が少なく安定・高速 | 障害物に弱く壁を透過しにくい |
| 802.11ax | Wi-Fi 6/6E | 2.4/5/6GHz | 混雑に強い（OFDMA技術）。6GHz帯はさらに高速 | 対応端末が必要。6GHzはさらに障害物に弱い |
| 802.11be | Wi-Fi 7 | 2.4/5/6GHz | 超低遅延。複数帯域の同時利用（MLO）が可能 | 機材コストが高い |

## 4. 研究デザインと実験計画

### 施策：多点設置・セル小規模化

アクセスポイント（AP）の数を増やし、1台あたりのカバーエリア（セル）を小さくする。端末とAPの距離が縮まることで、高周波帯（5GHz/6GHz）の高速通信を維持しやすくなる。

**要検証の課題：**
* 隣り合うAP同士の電波干渉（チャネル干渉）の制御
* 移動時のスムーズな接続切り替え（ローミング）の最適化

### 実験条件の統制

1. 計測に使用する端末（スマホやPC）の機種・OSバージョンを統一する（端末アンテナ性能の差を排除するため）。
2. 施策前・施策後を同じ時間帯・同じ混雑度の条件で計測する。
3. 本校（標準的な鉄筋コンクリート造）での最適解を導き出し、県内他校のモデルケースとなる設計を意識する。

---

## 5. 計測方法と評価指標

### ① 物理層・電波強度

* **RSSI（受信信号強度）：** 単位はdBm。一般に−60dBm以上なら良好、−80dBm以下は切断リスクあり。
* **SNR（信号対雑音比）：** 背景ノイズに対してWiFi電波がどれだけ強いかの比率（dB）。数値が高いほど高品質。

### ② ネットワーク層・通信品質

* **スループット（Throughput）：** 実際の通信速度（Mbps）。アップロード・ダウンロード双方を計測。
* **パケットロス率：** 送信データの何%が途中で消失したか。Web会議・CBT等の安定性に直結。
* **レイテンシ・ジッター：** 応答速度（遅延時間）とそのばらつき。

### ③ 計測ツールとアプローチ

* **ヒートマップ作成：** NetSpotなどの専用ソフトで間取り図上にRSSIを可視化し、電波の死角をあぶり出す。
* **定点観測：** 特定の座席・部屋の隅で、時間帯（混雑時・空いている時）ごとの変化を計測。
* **移動観測：** 歩きながら計測し、AP間のローミング時の瞬断有無を確認。

## 6. 研究プロセス（フェーズ別）

| フェーズ | 内容 |
| :--- | :--- |
| **課題定義フェーズ** | 校内での不満の集約、改善アプローチの仮説立て |
| **施策前計測フェーズ** | 現行環境でのヒートマップ作成、スループット・パケットロス率の計測（ベースライン取得） |
| **実証実験フェーズ** | 特定教室へのAP仮設・設定変更を行い、施策前後のデータを比較検証 |
| **コスト試算フェーズ** | 全校横展開時の工事費・機器代の試算、段階的導入プランの策定 |
| **発表準備フェーズ** | 提案書・スライドの作成と発表練習 |

## 7. 最終アウトプット（スライド発表構成案）

本研究の成果は、教育委員会への設備投資提案書を念頭に置いた以下の構成でスライドにまとめる。

| スライド | 内容 |
| :--- | :--- |
| 表紙 | テーマ・班名 |
| 背景と目的 | GIGAスクール構想・デジタル教科書との連動、電波不良による授業の機会損失、防災拠点としての通信インフラ強靭化 |
| RQと仮説 | ルーター増設で何がどう改善されるか |
| 前提知識 | WiFi規格の比較、電波特性の基礎 |
| 現状（施策前データ） | 電波ヒートマップ、パケットロス率の数値 |
| 実証実験の結果（施策後データ） | AP増設後の比較計測結果 |
| 考察 | 何%改善されたか、チャネル干渉・ローミングの課題 |
| 予算試算と導入プラン | 全校横展開コスト、段階的整備プラン、補助金活用の可能性 |
| 結論・提言 | 県内他校へのモデルケースとしての提案 |
