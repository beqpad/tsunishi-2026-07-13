# AI vs 人間による予定管理の比較研究

## 1. 研究の背景と目的

AI技術の発展に伴い、従来は人間（生徒自身・教師・塾講師）が手帳や紙を使って行っていた予定管理をAIで代替・補助する可能性が注目されている。本研究では、定期テスト対策を身近な例として用いながら、「AIによる予定管理」と「人間・手書きによる予定管理」が、達成感・効率性・心的負担の軽減・実益（得点向上）にどのような違いをもたらすかを科学的に比較検証する。

---

## 2. リサーチクエスチョンと仮説

**RQ：** AIによる予定管理と人間による予定管理では、どのような差が生まれるのか？

**仮説（複数）：**
* AIを使えば課題を逆算的に計画できるため、手動よりも計画的に物事を進められるのではないか
* フィードバックによる振り返りの促進と個人最適化は、手帳で自分なりのスケジューリング形式を確立するよりも早いのではないか
* 計画倒れや予定がズレたときの心理的ハードルを、AIなら下げられるのではないか
* AIは気分によって教科を変えられるため、テンションが低いときでも効率的にできるのではないか
* **手書きの方が記憶に残りやすく、達成感が目に見えやすいため、予定管理の効果がより出るのではないか**（←人間・手書き優位の仮説）

## 4. 研究デザインと実験計画

### 比較グループ

| グループ | 管理手法 | 具体的な方法 |
| :--- | :--- | :--- |
| **A群：AI管理グループ** | AIプロンプトによる管理 | 30分単位のタスク分解、忘却曲線に基づく3回復習、週次の自動即時リスケジュール |
| **B群：人間・手書きグループ** | 人間（生徒自身・教師・塾講師）または手帳・紙による管理 | 週1〜2回の面談または自己管理ベースで計画作成・修正 |

### 前提条件の統制

* 参加者の初期学力（過去のテスト平均点・偏差値）
* 目標とするテストの難易度・範囲
* 1日あたりに確保できる最大学習時間

---

## 5. 計測方法と評価指標

### ① 効率性（Time Efficiency）

* **測定：** 計画作成・リスケジュールに要した時間（分）、タスク未達成率
* **着目点：** AIは24時間即時修正できるが、人間は次の面談まで待つタイムラグが発生する

### ② 心的負担の軽減（Mental Burden）

* **測定：** 「計画通りいかなかった時の焦り」「遅れを報告する際のストレス」を数値化した心理アンケート（リッカート尺度）
* **着目点：** AIは対人ストレスがゼロだが、共感・励ましがなく孤独感が生じるリスクもある

### ③ 達成感（Sense of Achievement）

* **測定：** 完了した30分コマの総数、「自分でやりきった感覚があるか」アンケート、手書きグループの「消した・塗りつぶした項目数」
* **着目点：** AIは「自己効力感（ゲームのクエストをクリアするような感覚）」、手書きは「視覚的な達成感」と、質が異なる可能性がある

### ④ 実益（学力・得点向上）

* **測定：** テストの得点の伸び率（事後点数 ー 事前点数）
* **着目点：** AIの忘却曲線に基づく機械的な3回復習は、暗記科目の定着で人間の勘に頼る計画を上回りやすい

## 6. 研究プロセス（フェーズ別）

| フェーズ | 内容 |
| :--- | :--- |
| **準備フェーズ** | 事前学力測定、グループ分け（学力均等化）、AI用プロンプトの作成、手書き用フォーマット設計 |
| **実践フェーズ** | 2〜3週間、各グループが自分の管理手法でテスト勉強を実施 |
| **中間調整フェーズ** | A群：週1回AIへの進捗入力・即時リスケ。B群：週1回の面談または自己修正 |
| **事後データ収集フェーズ** | テスト結果の回収、心理・行動アンケート・インタビューの実施 |
| **分析・発表準備フェーズ** | データ集計・グラフ化・考察・スライド作成 |
