# 【研究計画ガイドライン】インバウンド創出と観光公害対策に関する研究ステップ

本資料は、観光地化の意図的な創出（攻めの観光戦略）や、観光公害（オーバーツーリズム）の抑制・解決（守りの観光戦略）を研究テーマとする班のための、計画書（README）作成および研究推進のステップガイドです。

指定された「共通セクション構成（1〜7）」に沿って、各フェーズでやるべきことを明確化しています。

---

## 1. 研究の背景と目的
**「なぜこのテーマか、何を明らかにしたいか」を定義するステップ**

* **【STEP 1-1】問題意識の言語化（アプローチの選定）**
  * これまでの事例を参考に、「海外資本の誘致」「IP・アニメ聖地化」「SNSバイラル」「国際評価・ブランド化」または「観光公害対策（物理的動線分離・価格制御）」の中から、自分たちの班が検証したい切り口を1つ選択する。
* **【STEP 1-2】研究目的の設定**
  * 選択した切り口が「まだ無名な地方に意図的に再現可能か」、あるいは「発生している観光公害を住民の生活を守りつつ解決可能か」のどちらに軸足を置くかを明確にする。
* **【READMEへの記載ポイント】**
  * 「〜という課題があるため、本研究では〜のメカニズム（または解決策）を明らかにすることを目的とする」の形で論理的に記述する。

## 2. リサーチクエスチョンと仮説
**「問いと、それに対する仮の答え」を構造化するステップ**

* **【STEP 2-1】リサーチクエスチョン（RQ）の策定**
  * 単なる疑問ではなく、データで測定可能な「〜すると、〜はどうなるか？」という形の具体的な問いを作る。
  * *観光創出の例:* 「海外インフルエンサーに特定の『記号を掛け合わせた構図（例：鳥居×富士山）』を投稿してもらうと、外国人旅行者の訪問意向はどのように変化するか？」
  * *公害対策の例:* 「観光特急バスの導入と住民優先乗車制度の組み合わせによって、地元住民の通勤時間帯の混雑ストレスはどの程度軽減されるか？」
* **【STEP 2-2】仮説の構築（メカニズムの予想）**
  * 先行研究やこれまでの事例に基づき、RQに対する「仮の答え」を論理的に予測する。
  * *仮説の例:* 「外国人観光客が認識しやすい日本の記号が2つ以上含まれる画像は、1つの場合と比べて、SNS上でのエンゲージメント率が2倍以上になる（訪問動機が強くなる）」

## 3. 前提知識・現状整理
**「研究の土台となる事実や既存課題」をインプット・整理するステップ**

* **【STEP 3-1】先行事例のパターンレビュー**
  * ニセコや白馬（海外資本型）、新倉山浅間公園（SNSバイラル型）、京都市や富士山（観光公害・規制対策型）など、これまでに挙げられた代表的事例の「きっかけ」と「現状の課題」を整理し、自分たちの研究との共通点・相違点を浮き彫りにする。
* **【STEP 3-2】ターゲット地域のボトルネック把握**
  * 本研究で実験対象（または調査対象）とする自治体や地域の現状（例：交通インフラの容量、多言語対応の有無、高齢化率など）を、統計データや自治体HPから抽出して整理する。

## 4. 研究デザインと実験計画
**「条件を揃えて比較する軸（検証方法）」を設計するステップ**

* **【STEP 4-1】比較軸（独立変数・統制変数）の決定**
  * 何を変化させて比較し（比較軸）、何を同じ条件として揃えるか（条件統制）を決める。
  * *実験アプローチの例（アンケート/ABテスト）:* 外国人留学生や海外のSNSユーザーを対象に、「通常の地方の風景写真（条件A）」と「戦略的に日本の記号を掛け合わせた映える写真（条件B）」を見せ、訪問意向度や魅力を感じる度合いを比較する。
* **【STEP 4-2】対象者（サンプリング）の選定**
  * 調査対象は誰か、何名からデータを集めるかを具体的に設定する（例：学内の外国人留学生50名、特定の海外コミュニティのユーザーなど）。

## 5. 計測方法と評価指標
**「何をどう測るか（評価の基準）」を具体化するステップ**

* **【STEP 5-1】客観的データの指標化（定量的指標）**
  * 収集する数値データを定義する。
  * *観光創出の指標:* 訪問意向度（5段階リッカート尺度）、SNSの「いいね数」「保存数」「シェア数」のエンゲージメント率。
  * *公害対策の指標:* 住民のバス乗車待ち時間（分）、混雑に対する住民の主観的ストレス値（1〜10のスケール）。
* **【STEP 5-2】主観的データの収集（定性的指標）**
  * 数値化できない理由や感情を補足するための方法を決める（例：自由記述アンケートやインタビューの実施、テキストマイニングによる頻出単語の分析など）。

## 6. 研究プロセス（フェーズ別）
**「序盤・中盤・終盤」の流れを日付なしのワークフローに落とし込むステップ**

* **【序盤：インプット＆研究設計フェーズ】**
  * 関連する文献や先行事例を調査し、実験用の素材（写真、架空の観光施策案、アンケートフォームなど）を作成する。README（研究計画書）を完成させ、教員・TAの承認を得る。
* **【中盤：データ収集＆実験フェーズ】**
  * 対象者へのアンケート実施、実験（ABテスト）、あるいは実際のSNS上でのスクレイピングやハッシュタグ分析を行い、生データをスプレッドシート等に集約する。
* **【終盤：分析＆考察・資料作成フェーズ】**
  * 集まったデータを定量・定性の両面から分析し、仮説が支持されたかどうかを検証する。結果に基づき、具体的な政策提案やリゾート管理手法を考察し、発表スライドの作成に移る。

## 7. 最終アウトプット（スライド発表構成案）
**「成果を論理的に伝えるための構成」を事前に決めておくステップ**

最終発表で論理破綻が起きないよう、READMEの段階で以下の章立て（全10〜12枚程度）を意識して設計させます。

1. **タイトル・班員一覧**
2. **研究の背景と目的**（なぜこのインバウンドテーマ/公害テーマを選んだか）
3. **リサーチクエスチョンと仮説**（何を検証したか、どう予想したか）
4. **先行研究・現状の課題**（これまでのニセコや京都等の事例、対象地の現状分析）
5. **研究デザイン・調査方法**（どのような比較実験やアンケート、データ収集を行ったか）
6. **分析結果（定量データ）**（グラフや統計数値を用いた実証結果）
7. **分析結果（定性データ）**（自由記述やインタビューから見えたファンの本音・インサイト）
8. **考察と仮説の検証**（仮説は検証されたか、なぜその結果になったのかの要因分析）
9. **地方自治体/企業への具体的な政策提案**（本研究から導き出された、明日から使える観光創出/公害対策ステップ）
10. **研究の限界と今後の展望 / 参考文献一覧**
