# 【探究活動・研究計画】AI指導法の違いにおける学習効果の比較検証

## 1. 研究の背景と目的
* **課題**：同じ学習時間において、AIの「対話型指導（双方向）」と「一方通行の解説型指導」では、理解度・記憶定着・学習満足度にどのような差が出るか。
* **仮説**：能動的なアウトプットを伴う「対話型指導」の方が、脳が活性化し、すべての指標において高い学習効果を発揮する。

---

## 2. 実験のデザインと条件統制（公平性を保つ工夫）

発表時に「条件がバラバラではないか」と突っ込まれないためのルール設定です。

* **被験者のグループ分け（2群比較）**
  * クラス内、または学年内で「定期テストの平均点が同等」になるよう、A班（対話型）とB班（解説型）に等分する。
* **学習コンテンツの統一**
  * 全員が「これまでに授業で習っていない初見の概念」を学習する。
  * 例：情報科の「暗号資産の仕組み」、歴史の「マイナーな近代史事件」、理科の「量子力学の超基礎」など。
* **AIの役割設定（プロンプトによる演じ分け）**
  * **対話型（A班）**：ソクラテスメソッド（問答法）を使用。「君はどう思う？」と質問を投げかけ、生徒の答えを褒めつつ次のステップへ導く。
  * **解説型（B班）**：超一流の塾講師風。質問は一切受け付けず、完璧に整理された分かりやすい解説文を一方的に出力し続ける。
* **学習時間の固定**
  * どちらのグループも「きっちり20分間」でAIとの学習を終了させる。

---

## 3. 計測・データ化のアプローチ（多角的なエビデンス）

### ① 理解度の可視化（「自分の言葉」を数値化）
点数だけでなく、「どれだけ深く理解したか」のプロセスを可視化します。

* **1分間要約の文字起こし（音声入力の活用）**
  * **方法**：学習直後、スマホの音声入力を使って「今学んだ内容を、何も見ずに1分間で説明して」と指示。
  * **データ化**：文字起こしされた文章の「総文字数」や、絶対に外せない重要キーワードが何個入っていたかをカウントしてグラフ化。
  * **狙い**：対話型の方が「自分の言葉でスラスラ話せる（＝文字数が多い）」という結果を証明する。
* **ミニ授業テスト（再現性の検証）**
  * **方法**：各グループから数名をランダムに選び、ホワイトボードの前で「先生役」として3分間のミニ授業をしてもらい、その様子を録画する。
  * **データ化**：言葉に詰まった回数（「えーっと」などの数）や、身振り手振りの大きさ、板書の分かりやすさをルーブリック（評価基準表）を作って採点。

### ② 記憶定着の可視化（忘却の「スピード」を計測）
人間の記憶は時間の経過とともに失われるため、その「耐え方」を追跡します。

* **抜き打ちゲリラテスト（期間ごとの追跡）**
  * **方法**：実験の「翌朝の朝のホームルーム」と「1週間後」に、予告なしでGoogleフォームを使った3問ずつの小テストを配信する。
  * **データ化**：正答率の「下がり幅（減衰率）」を折れ線グラフにする。
  * **狙い**：「解説型は翌朝にガクッと忘れるが、対話型は1週間後も記憶がキープされている」というエビングハウスの忘却曲線に沿った推移をビジュアルで示す。

### ③ 学習満足度の可視化（感情と心理を数値化）
アンケートの「5段階評価」だけでなく、高校生らしいリアルな行動を数値化します。

* **体感時間のズレ（タイムワープ度 / 没頭度メーター）**
  * **方法**：実際の学習時間は20分で統一。終了直後に「今、何分くらい勉強していたと感じた？」と質問する。
  * **データ化**：【体感時間 ÷ 20分（実際の時間）】で「没頭度」を算出。
  * **狙い**：対話型は「え！もう20分？（体感10分＝没頭度0.5）」、解説型は「長かった…（体感30分＝没頭度1.5）」という心理的ストレスの差をメーター風のグラフにする。
* **リピート意向率（行動経済学アプローチ）**
  * **方法**：実験終了後、「明日もこのAIで勉強したいですか？」というボタンを設置する。
  * **データ化**：「はい」と答えた人の割合（％）を円グラフで比較。

## 4. 発表のステージで「映える」ビジュアルデータ

スライドに載せるだけで、聴衆や先生の目を惹きつけ、説得力が跳ね上がるデータの見せ方です。

* **テキストマイニング（ワードクラウドによる感情対比）**
  * **方法**：実験後の自由記述アンケート（感想文）を、無料のワードクラウド作成ツールに投入する。
  * **データ化**：多く使われた言葉ほど大きく表示される画像を作成。
  * **見せ方**：解説型は「眠い、長い、退屈」、対話型は「おもしろい、あっという間、わかった」と、見た瞬間に一発で違いが伝わるスライドにする。
* **学習中の「姿勢」と「視線」のタイムラプス比較**
  * **方法**：被験者の承諾を得て、実験中の様子を横からスマホの「タイムラプス（コマ送り動画）」で撮影する。
  * **データ化**：画面と顔の距離（前のめり度）、背筋の伸び具合の変化を、静止画として切り出す。
  * **見せ方**：モザイクをかけた2つのグループの写真を並べ、「開始5分後」「15分後」の姿勢の崩れ方の差を提示。「身体の動きからも集中度の違いは明らかです」とアピールする。
