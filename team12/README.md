# AI指導法の違いにおける学習効果の比較検証

## 1. 研究の背景と目的

学校やオンライン学習でAIを活用する機会が増える中、AIの「指導スタイルの違い」が学習効果にどのような差をもたらすかはまだ十分に検証されていない。本研究では、学習者が受け身になりがちな「一方通行の解説型指導」と、積極的なアウトプットを促す「対話型指導」を比較することで、より効果的なAI活用の在り方を探る。

---

## 2. リサーチクエスチョンと仮説

**RQ：** 同じ学習時間において、AIの「対話型指導（双方向）」と「一方通行の解説型指導」では、理解度・記憶定着・学習満足度にどのような差が出るか。

**仮説：** 能動的なアウトプットを伴う「対話型指導」の方が、脳が活性化し、すべての指標において高い学習効果を発揮する。

## 4. 研究デザインと実験計画

### 比較グループ（2群）

* **A班（対話型）：** ソクラテスメソッド（問答法）を使用。「君はどう思う？」と問いかけ、生徒の答えを認めながら次のステップへ誘導する。
* **B班（解説型）：** 超一流の塾講師風。質問は一切受け付けず、完璧に整理された解説文を一方向に出力し続ける。

### 実験条件の統制

* **被験者のグループ分け：** クラス内または学年内で定期テストの平均点が同等になるようA班・B班に等分する。
* **学習コンテンツの統一：** 全員が「授業でまだ習っていない初見の概念」を学習する（例：暗号資産の仕組み、マイナーな近代史事件、量子力学の超基礎）。
* **学習時間の固定：** どちらのグループも「きっちり20分間」でAIとの学習を終了させる。

---

## 5. 計測方法と評価指標

### ① 理解度（「自分の言葉」を数値化）

* **1分間要約の文字起こし：** 学習直後、スマホの音声入力で「今学んだ内容を何も見ずに1分間で説明して」と指示。文字起こしされた文章の総文字数と重要キーワードの含有数をカウントしてグラフ化する。
* **ミニ授業テスト：** ランダムに選んだ数名がホワイトボードの前で3分間の「先生役」授業を行い録画。言葉に詰まった回数・身振り手振りの大きさ・板書の分かりやすさをルーブリック（評価基準表）で採点する。

### ② 記憶定着（忘却の「スピード」を計測）

* **抜き打ちゲリラテスト：** 実験の翌朝と1週間後に、予告なしでGoogleフォームの小テスト（3問ずつ）を配信する。正答率の「下がり幅（減衰率）」を折れ線グラフ化し、エビングハウスの忘却曲線と照合する。

### ③ 学習満足度（感情と心理を数値化）

* **体感時間のズレ（没頭度メーター）：** 学習終了直後に「今、何分くらい勉強していたと感じた？」と質問。【体感時間 ÷ 実際の時間（20分）】で没頭度を算出し、グラフ化する。
* **リピート意向率：** 実験終了後に「明日もこのAIで勉強したいですか？」ボタンを設置し、「はい」の割合（%）を円グラフで比較する。

| フェーズ | 内容 |
